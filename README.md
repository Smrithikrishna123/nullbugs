
# Null Bugs Website Rebuild 🚀

A redesigned and rebuilt version of the Null Bugs company website, created as part of a frontend/web development internship task.

---

# Project Overview

The goal of this project is to improve design, user experience, and performance of the website while maintaining a clean and professional structure.

**Key pages included:**

-Modern and responsive homepage
-Detailed About Us section
-Services page showcasing offerings
-Pricing page with clear plans and call-to-action

---

## Features

-Fully responsive design (mobile-friendly)
-Clean and modern UI/UX
-Easy navigation across pages
-WhatsApp integration for direct contact
-Structured and reusable code

---

## Technologies Used

-HTML5
-CSS3
-Flexbox for layout
-Font Awesome for icons

---

## Installation / How to Run

1.Download or clone the repository:git clone <repository_url>
2.Open index.html in your browser.
3.Navigate through pages using the navbar or footer links.

---

The design focuses on:
