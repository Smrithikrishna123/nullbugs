# Null Bugs Website Rebuild 🚀

This project is a redesigned and rebuilt version of the Null Bugs company website, created as part of a frontend/web development internship task.

---

## 🌐 Project Overview

The goal of this project is to improve the overall design, user experience, and performance of the website while maintaining a clean and professional structure.

The website includes:
- A modern and responsive homepage
- Detailed About Us section
- Services page showcasing offerings
- Pricing page with clear plans and call-to-action

---

## ✨ Features

- Responsive design (mobile-friendly)
- Clean and modern UI/UX
- Easy navigation across pages
- WhatsApp integration for direct contact
- Structured and reusable code

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design (Flexbox)

---

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open `index.html` in your browser
3. Navigate through pages using the navbar

---

## 💡 Design Approach

The design focuses on:
- Simplicity and readability
- Clear content hierarchy
- User-friendly interface
- Business-oriented layout

---

## 📞 Contact Feature

The "Get Free Consultation" buttons are integrated with WhatsApp, allowing users to directly connect with the company.

This project demonstrates my ability to design and develop a responsive and user-friendly website using core frontend technologies.
